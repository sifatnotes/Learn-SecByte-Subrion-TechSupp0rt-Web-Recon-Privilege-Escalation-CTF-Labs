## Learning Path

A practical progression through this collection can be:

1. **Start with reconnaissance**
   - Support Trail Recon
   - Subrion Sleuth
   - Subrion Shadow Recon

2. **Practice web discovery**
   - Panel Access Detour
   - Encoded Doorways
   - Redirected Truth

3. **Explore application-specific security**
   - WordPress Credential Harvest
   - Subrion Siphon
   - Panel Breach Tech Support

4. **Study access and shell concepts**
   - Reuse and Pivot TechSupp0rt Trail
   - Stabilize the Shell 2

5. **Study Linux privilege escalation**
   - Sudo GTFOBins Iconv Trap

This sequence moves from reconnaissance and discovery toward application security, access concepts, shell handling, and Linux privilege-escalation techniques.

## How to Use the Labs

1. Open a lab from the collection.
2. Read the lab instructions before interacting with the target.
3. Perform all testing only against the systems explicitly provided for the exercise.
4. Record commands, observations, discovered technologies, and lessons learned.
5. Focus on understanding the underlying security concept rather than simply obtaining a flag.
6. After completing a lab, document the technique and defensive lesson in your own notes.

Useful areas to practice include:

- Web reconnaissance
- Application enumeration
- Authentication and credential security
- WordPress security
- Subrion application analysis
- Encoded resource discovery
- Redirect analysis
- Shell stabilization
- GTFOBins research
- Sudo-based privilege escalation

Do not use techniques from these labs against systems without explicit authorization.
